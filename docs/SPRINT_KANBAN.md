# StudyMate 칸반 스프린트 운영

## 상태 흐름
Backlog → To Do → In Progress → Review → Done

GitHub Projects 보드의 Status 필드에 위 옵션을 만들고, 새 이슈는 Backlog에 둡니다. 작업을 시작할 때 To Do, 구현 중 In Progress, 검토 요청 시 Review, 완료 및 확인 후 Done으로 이동합니다.

## 라벨
- 유형: `bug`, `feature`, `documentation`, `enhancement`
- 우선순위: `priority:high`, `priority:medium`, `priority:low`
- 영역: `frontend`, `backend`, `testing`

## 마일스톤
- Sprint 1: 핵심 학습 플래너 기능
- Sprint 2: AI·통계·테스트·문서화

## 운영 원칙
- 각 이슈는 완료 조건(acceptance criteria)을 가져야 합니다.
- 한 번에 진행 중인 작업을 제한하고, Review 상태에서 검증 후 Done으로 이동합니다.
- GitHub Projects의 Status는 이슈 라벨과 별개입니다. 마일스톤은 스프린트 목표/진척 추적에 사용합니다.
